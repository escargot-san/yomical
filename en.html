What is YomiCal?

It reads your Google Calendar events aloud with TTS, at the volume you set.

That's all it does. A simple app for Android.

FEATURES

Features

At each event's notification time, YomiCal reads the event aloud with TTS at the volume you choose.

Instead of just a beep, it tells you what the event is, which helps you avoid problems like these.

Sound familiar?

  • The notification sound is too short or too quiet to notice.
  • You have to add a separate event just to be reminded when something ends, and sometimes you forget.
  • Your phone is on vibrate, so you miss the notification.
  • Your phone switched to silent mode without you noticing.
  • The event is in your notification shade, but you never see it.
  • You set an alarm for an event, but can't remember what it was for.
  • You stop the alarm on reflex and forget you had somewhere to be.

YomiCal speaks the event itself at a fixed volume, so you don't miss it.

SETTINGS

Settings

Screenshots show the Japanese UI.

Volume

Choose how the read-out volume is decided.

  • Follow system volume: uses your phone's current volume.
  • Use fixed app volume: reads at the volume set with the slider (0–100%), regardless of the phone's volume.
  • Vibrate only: no sound, just vibration.

Tap "Test playback at this volume" to hear how it sounds.

Prefixes to read aloud (comma-separated)

Only events whose titles start with one of these prefixes are read aloud. Separate multiple prefixes with commas (,).

Example: set yomical:,rc:, then add an event titled "yomical:Dentist" and it will be read aloud.

End-time prefixes (comma-separated)

Events whose titles start with one of these prefixes are also read aloud at their end time, so you don't need a separate event to mark the end.

Example: set ye: and add "ye:Meeting" to be alerted when the meeting ends.

Use alternative text at end time

When on, events with an end-time prefix are read using your custom text instead of the event title.

Alarm auto-stop timer

Set how long the alert keeps going before it stops automatically, so it won't keep running if you miss it.

Read-out options

  • Also read event details (description): reads the event's description after the title.
  • Vibrate while speaking: vibrates the phone during the read-out.

Language

Choose the app's display language.

Theme

Choose the color scheme, such as dark.

All-day event read-out time

All-day events have no start time, so choose when they should be read aloud.

Also notify events without a prefix

When on, regular events without a prefix (such as yomical:) are also announced, using a fixed text you set.

Start on boot

Check "Start automatically on boot" and YomiCal will begin running again after your phone restarts.

Calendar filter

Turn on "Filter by calendar account" to read aloud only events from the calendars you select.

Save settings and start service

After changing settings, tap this button at the bottom. Your settings are saved and the read-out service starts.
